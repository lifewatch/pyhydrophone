.. currentmodule:: pyhydrophone

Install
=======

Using pip distribution
----------------------
.. code-block::

    pip install pyhydrophone


Using git clone
---------------

1. Clone the package

.. code-block::

    git clone https://github.com/lifewatch/pyhydrophone.git


2. Use uv to install the project dependencies in a dedicated virtual environment

.. code-block::

    uv sync


3. Build the project

.. code-block::

    uv build
